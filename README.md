# shootan-j2me

This is a silly j2me port of [shootan](https://github.com/InviseDivine/shootan) online game made by my friend.

# Progress

- [x] Connection to server
- [x] Level receiving
- [ ] Game protocol implementation (75% done)
- [x] Drawing other players
- [x] Weapons and shooting
- [x] Offline mode
- [ ] Bluetooth server mode

![img](./screenshot.png)

# Resources used
- [shootan](https://github.com/InviseDivine/shootan) - the base game
- [enet-j2me](https://github.com/Kolyah35/enet-j2me) - networking
- [compress-j2me](https://github.com/igorgatis/compress-j2me) - decompressing levels
- [rd-132211](https://github.com/thecodeofnotch/rd-132211) - the base game use timer and AABB from this game
